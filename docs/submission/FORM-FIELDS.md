## Project name

SplitReceipt

## Tagline

Shared bills with recoverable USDC payment receipts.

## Stage

Prototype / testnet demo

## Short description

SplitReceipt lets a group split a shared bill in USDC on Arc Testnet (test USDC, no real value): one person creates the bill with a recipient and payers, each payer sends their exact share with a wallet transaction confirmation (no ERC-20 approval step), and the app recovers a verified onchain receipt for every payment directly from Arc event logs — no custodial backend, no private indexer.
